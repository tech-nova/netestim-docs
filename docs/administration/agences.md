# Agences

!!! info "Réservé aux administrateurs"

Les données de Netestim sont cloisonnées par agence : les utilisateurs d'une agence ne voient que les projets, dossiers, biens, contacts et modèles de leur agence. Chaque utilisateur est rattaché à une seule agence.

Ouvrez le menu de votre profil, puis **Gestion des agences**. La liste des agences s'affiche à gauche ; le formulaire de l'agence sélectionnée, à droite.

## Créer une agence

1. Cliquez sur **Créer une agence**.
2. Renseignez :

    | Champ | Description |
    |---|---|
    | **Nom de l'agence** | Obligatoire |
    | **Code de l'agence** | Obligatoire. Deux lettres majuscules, par exemple `PA`. |
    | **Adresse de l'agence** | Adresse, code postal et ville obligatoires ; nom du destinataire, complément, région et pays facultatifs. |

3. Cliquez sur **Enregistrer**.

!!! warning "Choisissez bien le code"
    Le code de l'agence ne peut plus être modifié après la création. Il préfixe la référence de chaque dossier d'expertise de l'agence : par exemple `PA-25-02-12` pour le douzième dossier de l'agence, créé en février 2025.

Une fois l'agence créée, créez-y au moins un compte manager ou administrateur (voir [Utilisateurs](utilisateurs.md)).

## Modifier une agence

Sélectionnez l'agence dans la liste, modifiez son nom ou son adresse, puis cliquez sur **Enregistrer**.

## Supprimer une agence

Une agence ne peut être supprimée que si elle ne contient **aucune donnée** : ni utilisateur, ni projet, ni dossier, ni bien, ni contact, ni document, ni tâche, ni modèle.

Si elle en contient, le bouton **Supprimer** est inactif ; survolez-le pour voir les données qui l'en empêchent. Sinon, cliquez sur **Supprimer** et confirmez : la suppression est définitive.
