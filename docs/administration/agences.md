# Agences

!!! info "Réservé aux administrateurs"

Les données de Netestim sont cloisonnées par agence : les utilisateurs d'une agence ne voient que les projets, dossiers, biens et contacts de leur agence.

La liste des agences est accessible depuis le menu de votre profil.
