# L'interface

## Le menu

Le menu, à gauche de l'écran, donne accès aux grandes listes de l'application :

| Entrée | Contenu |
|---|---|
| **Projets** | Tous les projets que vous pouvez consulter |
| **Dossiers** | Tous les dossiers d'expertise, quel que soit leur projet |
| **Biens immobiliers** | Tous les biens expertisés |
| **Estimations** | Les dernières estimations saisies |
| **Tâches** | Vos tâches et celles de votre équipe |
| **Contacts** et **Adresses** | L'annuaire partagé de l'agence |
| **Corbeille** | Les éléments supprimés, que vous pouvez restaurer |

Lorsque vous ouvrez un projet, un dossier ou un bien, le menu affiche en plus les rubriques de cet élément (par exemple **Caractéristiques**, **Surfaces**, **Photos** pour un bien).

Le menu peut être replié pour laisser plus de place au contenu : voir [Personnaliser l'affichage](personnalisation.md).

## Le fil d'Ariane

En haut de chaque page, le fil d'Ariane indique où vous vous trouvez, par exemple :

> Accueil › Projets › Projet n°12 › Dossiers

Chaque segment est cliquable et vous ramène au niveau correspondant.

## Les listes

Les listes (projets, dossiers, biens…) fonctionnent toutes de la même façon :

- le champ **Rechercher** filtre la liste au fil de la saisie ;
- un clic sur un en-tête de colonne trie la liste ;
- les boutons de la colonne **Actions** permettent de consulter, modifier ou supprimer un élément, selon vos [droits](roles.md).

!!! info "Vous ne voyez pas un élément ?"
    Une liste n'affiche que ce que votre rôle vous permet de consulter. Un expert, par exemple, ne voit que les projets sur lesquels il intervient. Voir [Rôles et droits](roles.md).
