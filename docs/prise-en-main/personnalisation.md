# Personnaliser l'affichage

Le panneau **Personnalisation du thème** permet d'adapter l'apparence de Netestim. Pour l'ouvrir, cliquez sur la roue dentée, sur le bord droit de l'écran.

!!! note
    Ce panneau n'est disponible que sur les grands écrans (ordinateur).

Les réglages s'appliquent immédiatement et sont conservés pour vos prochaines visites.

## Apparence

| Réglage | Choix |
|---|---|
| **Couleur principale** | Une couleur proposée, ou une couleur libre via la palette |
| **Thème** | **Clair**, **Sombre**, ou **Système** (suit le réglage de votre ordinateur) |
| **Style** | **Par défaut** (cartes avec ombre) ou **Bordé** (cartes avec bordure) |
| **Menu semi-sombre** | Menu foncé sur une page claire (thème clair uniquement) |

## Mise en page

| Réglage | Choix |
|---|---|
| **Menu** | **Déplié** (libellés visibles) ou **Replié** (icônes seules, le menu se déplie au survol) |
| **Contenu** | **Compact** (largeur limitée) ou **Large** (toute la largeur de l'écran) |

## Revenir aux réglages d'origine

Lorsqu'un réglage diffère de la configuration d'origine, un point rouge apparaît sur le bouton de réinitialisation (flèche circulaire, en haut du panneau). Cliquez dessus pour tout rétablir.
