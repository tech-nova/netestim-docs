# Se connecter

## Première connexion

Votre compte est créé par un administrateur ou un manager de votre agence. Vous recevez ensuite l'adresse de Netestim et vos identifiants.

1. Ouvrez l'adresse de Netestim dans votre navigateur.
2. Saisissez votre **email** et votre **mot de passe**.
3. Cochez **Se rappeler de moi** si vous travaillez sur un poste personnel.
4. Cliquez sur **Se connecter**.

!!! tip "Langue"
    L'interface est disponible en français et en anglais. Choisissez la langue depuis l'écran de connexion ou depuis le menu de l'application.

## Mot de passe oublié

1. Sur l'écran de connexion, cliquez sur **Mot de passe oublié ?**
2. Saisissez l'email de votre compte, puis cliquez sur **M'envoyer le lien**.
3. Ouvrez le lien reçu par email. Il vous connecte et vous permet de choisir un nouveau mot de passe.

Le nouveau mot de passe doit contenir **au moins 8 caractères**. Saisissez-le deux fois à l'identique, puis cliquez sur **Mettre à jour le mot de passe**.

!!! note "Vous ne recevez pas l'email ?"
    Vérifiez votre dossier de courriers indésirables. Si l'email n'arrive toujours pas, contactez l'administrateur de votre agence : il peut vérifier l'adresse enregistrée sur votre compte.

## Verrouillage après inactivité

Si vous restez inactif un moment, Netestim **verrouille votre session** par sécurité. Pour reprendre là où vous en étiez, saisissez votre **code de déverrouillage**, puis cliquez sur **Déverrouiller**.

- Définissez ou modifiez ce code depuis votre profil : **Changer le code de déverrouillage**.
- Après plusieurs codes erronés, il faut patienter quelques minutes avant de réessayer.
- Sur un réseau que vous utilisez régulièrement (bureau, domicile), cochez **Faire confiance à ce réseau** pour ne plus être verrouillé sur ce réseau.

!!! warning "Pas encore de code ?"
    Si aucun code n'est défini sur votre compte, déconnectez-vous, reconnectez-vous, puis créez-en un dans votre profil.

## Se déconnecter

Ouvrez le menu de votre profil (votre avatar, en haut à droite), puis cliquez sur le bouton de déconnexion, en bas du menu.
