# Projets

Un projet regroupe tout ce qui concerne une mission confiée par un client : le donneur d'ordre, le chef de projet, les experts associés, le chiffre d'affaires et les dossiers d'expertise.

## Consulter les projets

Le menu **Projets** affiche la liste des projets que vous pouvez consulter, avec pour chacun le client, le propriétaire, le chef de projet, le statut et le nombre de dossiers.

Pour retrouver un projet, saisissez son nom dans **Rechercher un projet**.

## Créer un projet

!!! info "Expert : vous êtes le chef de projet"
    Un expert peut créer un projet, dont il est automatiquement le chef de projet : le champ **Chef de projet** est alors en lecture seule. Seuls les managers et les administrateurs peuvent désigner un autre chef de projet. Voir [Rôles et droits](../prise-en-main/roles.md).

1. Dans la liste des projets, cliquez sur **Nouveau Projet**.
2. Renseignez les **informations générales** :

    | Champ | Description |
    |---|---|
    | **Nom du projet** | Nom qui identifie la mission |
    | **Chef de projet** | Expert responsable du projet |
    | **CA (€)** | Chiffre d'affaires prévu |
    | **Référence du devis** / **de la facture** | Vos références comptables |
    | **Qualité** | Qualité du client pour ce projet |

3. Renseignez le **donneur d'ordre**, c'est-à-dire le client qui commande la mission.
4. Si besoin, renseignez un **propriétaire par défaut**. Il sera proposé dans chaque dossier du projet.
5. Cliquez sur **Créer le projet**.

## Modifier un projet

Ouvrez le projet, puis choisissez **Modifier** dans le menu. Depuis la page **Modification du projet**, vous pouvez changer les informations générales, le donneur d'ordre et le propriétaire par défaut.

### Changer de chef de projet

!!! info "Réservé aux managers et administrateurs"

Si l'ancien chef de projet a encore des tâches ouvertes, Netestim vous propose deux options :

- **Modifier et réaffecter** : les tâches ouvertes passent au nouveau chef de projet ;
- **Modifier sans réaffecter** : les tâches restent attribuées à l'ancien chef de projet.

L'ancien chef de projet reste associé au projet comme expert : il garde l'accès à ses dossiers.

## Associer des experts et ventiler le chiffre d'affaires

!!! info "Réservé aux managers et administrateurs"

La section **Ventilation du CA** de la page de modification liste les experts qui interviennent sur le projet, avec leur part du chiffre d'affaires.

1. Cliquez sur **Ajouter un expert**, choisissez l'expert et indiquez son **pourcentage**.
2. Le montant correspondant est calculé automatiquement à partir du CA du projet.
3. La somme des pourcentages doit être égale à **100 %**. Sinon, l'enregistrement est refusé.

Un expert associé au projet peut ensuite le consulter, le modifier et y créer des dossiers.

Si vous retirez un expert qui a encore des tâches ouvertes, Netestim vous demande de choisir un **nouveau responsable** pour ces tâches avant de le retirer.

## Supprimer un projet

Un projet supprimé part à la [corbeille](corbeille.md), avec ses dossiers et ses biens. Il peut y être restauré.
