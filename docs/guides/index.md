# Guides

Ces guides suivent le déroulement habituel d'une expertise :

1. **[Créer un projet](projets.md)** pour la mission confiée par le client.
2. **[Ouvrir un dossier d'expertise](dossiers.md)** dans ce projet.
3. **[Décrire chaque bien](biens.md)** du dossier : caractéristiques, surfaces, photos, documents.
4. **[Estimer les biens](estimations.md)** avec une ou plusieurs méthodes.
5. **[Valider le dossier et exporter le rapport](dossiers.md#valider-un-dossier)**.

Pour avancer au quotidien :

- les **[tâches](taches.md)** suivent ce qu'il reste à faire sur chaque projet ;
- les **[contacts et adresses](contacts-adresses.md)** forment l'annuaire de l'agence ;
- la **[corbeille](corbeille.md)** permet de récupérer un élément supprimé par erreur.
